      How to use templates:
      • L — any letter (upper or lower, if enabled)
      • U — uppercase letter
      • l — lowercase letter
      • # — digit
      • @ — special character
      • * — any allowed character
      • Any other character is inserted as-is (e.g., -, _)
      Examples:
      • LLL-###-@@@ — 3 letters, 3 digits, 3 special characters, separated by dashes
      • Ull#@# — 1 uppercase, 2 lowercase, 1 digit, 1 special, 1 digit
      • **** — 4 random allowed characters
      You can edit the template after selecting it. Leave the field empty to use standard password generation.
